# WhiteDock

Windows 桌面 Dock 与桌面组件工具。

## 下载

[下载最新版 Windows x64 安装包](https://github.com/Whitree-s/WhiteDock-Releases/releases/latest/download/WhiteDock-Setup-x64.exe)

[查看全部版本与更新说明](https://github.com/Whitree-s/WhiteDock-Releases/releases)

安装包内置电量助手、音频律动、桌面时钟、黑胶音乐，以及叠刻时钟、漫画墨线时钟皮肤。内置组件的安装与更新遵循软件的组件登记和版本规则。

## 软件更新

在 WhiteDock「设置 → 更新与恢复」中点击「检查更新」。软件仅在用户点击时联网检查，不会在启动或后台自动检查。

当前版本检查功能仅提示是否存在新版本；下载安装请使用上方下载链接。
